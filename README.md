# 🌻 Um Jardim de Recordações

Um projeto de desenvolvimento web criado com o objetivo de transformar fotografias em uma experiência digital especial. O **Um Jardim de Recordações** é um álbum fotográfico personalizado, desenvolvido para armazenar e apresentar 21 momentos especiais em uma interface delicada, intuitiva e responsiva.

## ✨ Funcionalidades

- Página inicial personalizada com identidade visual temática.
- Navegação entre a página inicial e o álbum fotográfico.
- Galeria interativa com espaço para 21 fotografias.
- Ampliação das imagens para melhor visualização.
- Navegação entre fotografias utilizando controles laterais e teclado.
- Layout responsivo, adaptado para celulares, tablets e computadores.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, responsividade, animações e organização dos elementos.
- **JavaScript:** criação e gerenciamento dinâmico da galeria e interação com as fotografias.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido como uma iniciativa pessoal, com o propósito de praticar e aprimorar conhecimentos em desenvolvimento Front-end, organização de arquivos, manipulação de elementos com JavaScript e construção de interfaces responsivas.

Além do aprendizado técnico, a proposta foi desenvolver uma experiência digital personalizada, unindo tecnologia, criatividade e memória afetiva.
