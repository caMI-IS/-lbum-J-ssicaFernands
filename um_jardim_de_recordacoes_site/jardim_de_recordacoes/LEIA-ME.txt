# Um Jardim de Recordações 🌻

Site estático com duas páginas:
- `index.html`: capa com a imagem enviada. O botão ilustrado na imagem é clicável.
- `album.html`: galeria para até 21 fotografias, com visualização ampliada.

## Como adicionar as fotos

1. Abra a pasta `img/fotos`.
2. Coloque suas 21 fotos nessa pasta.
3. Renomeie os arquivos exatamente assim:
   `foto1.jpg`, `foto2.jpg`, `foto3.jpg` ... até `foto21.jpg`.
4. Se suas imagens forem PNG ou WEBP, altere a extensão no arquivo `album.js` na linha `src: ...`.

A galeria mostra um espaço reservado para cada foto que ainda não foi adicionada. Assim, você consegue visualizar onde cada imagem ficará.

## Como testar

Abra o arquivo `index.html` no navegador. Clique no botão da capa para entrar no álbum.

## Publicar

Você pode enviar todos os arquivos para um repositório no GitHub e publicar pelo GitHub Pages, ou importar a pasta/projeto para a Vercel. Mantenha a estrutura das pastas.

A imagem de capa enviada já está incluída em `img/capa.png`.
